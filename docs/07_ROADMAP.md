## Resumen del Roadmap Actual

El desarrollo de CryptoDuels sigue un plan de **7 fases** con duración estimada de **10-16 semanas**:

### Fase 1: Diseño y UI Completa (2-3 semanas)
Perfeccionar todo el aspecto visual y UX antes de tocar contratos. Trabajar con mockups/datos falsos.

### Fase 2: Smart Contracts (2-3 semanas)
Desarrollo de contratos (GamePoolBase, CoinFlipPools, DiceDuelPools, RPSPools), tests unitarios, deploy a testnet.

### Fase 3: Integración Web3 (2-3 semanas)
Conectar UI de Fase 1 con contratos de Fase 2 usando wagmi + viem + RainbowKit.

### Fase 4: Testing Completo (1-2 semanas)
Probar todos los flujos en Polygon Mumbai testnet.

### Fase 5: Auditoría y Seguridad (2-4 semanas)
Auditoría externa obligatoria (OpenZeppelin/CertiK), corrección de issues.

### Fase 6: Producción (1 semana)
Deploy a Polygon Mainnet, verificación de contratos, lanzamiento público.

### Fase 7: Post-Lanzamiento
Marketing, iteración basada en feedback, nuevos juegos.
